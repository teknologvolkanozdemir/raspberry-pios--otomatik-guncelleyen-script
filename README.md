# raspberry-pios--otomatik-guncelleyen-script
tıklayın, admin şifrenizi girin, kendisi otomatik güncellesin, yükseltsin. siz uğraşmayın. rahatına düşkün olanlara özel hazırlandı.

## Kullanım

```
python3 guncelle.py
```

Script sırasıyla `sudo apt update` ve `sudo apt full-upgrade -y` komutlarını çalıştırır (admin şifreniz istenebilir).
